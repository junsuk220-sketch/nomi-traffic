개인정보처리방침

출근길 비서 (패키지명: nomi.commute)

시행일: 2026년 10월 29일

1. 개인정보처리방침

이 개인정보처리방침은 Android 앱 「출근길 비서」(이하 "앱")이 사용자의 기기에서 어떤 정보에 접근하고, 그 정보를 어떤 목적으로 어떻게 처리·저장·전송하는지 설명합니다. 앱은 사용자가 정해 둔 시각에 선택한 지하철역·버스정류장의 도착 정보를 조회하여 음성·알림으로 알려 주는 앱입니다.

요약
  • 회원가입·로그인이 없으며, 이름·전화번호·이메일 등 개인정보를 입력받지 않습니다.
  • 위치 권한과 마이크 권한을 요청하지 않으며, GPS 위치를 사용하지 않습니다.
  • 접근성 서비스·알림 접근 권한을 사용하지 않습니다.
  • 실시간 도착정보 호출량을 줄이기 위해 Cloudflare 기반 공용 캐시 서버를 사용합니다.
  • 광고 SDK, 분석·통계 SDK, 충돌 보고 SDK(Firebase, Google Analytics, Crashlytics 등)를 사용하지 않습니다.
  • 도착 정보 조회를 위해 선택한 역·정류장 식별 정보를 캐시 서버 또는 공공 API로 보냅니다(아래 9항).
  • 출근 경로·알람 설정은 사용자 기기 안의 앱 전용 저장소에만 저장되며, 앱을 삭제하면 함께 삭제됩니다.

4. 수집하는 개인정보

앱은 개발자가 받아 보관하는 형태로 개인정보를 수집하지 않습니다. 회원가입, 로그인, 결제, 사용자 입력 양식(이름·연락처 등), 파일 업로드 기능이 없습니다. 광고 ID, Android ID, 기기 일련번호, 전화번호 등 기기 식별자나 사용자 식별자를 읽지 않습니다.

다만 앱은 기능을 제공하기 위해 아래 5~9항의 정보에 기기 안에서 접근하고 처리하며, 일부는 기기 안에 저장하고, 도착 정보 조회 때 현재 조회하는 역·정류장 식별값을 공용 캐시 서버 또는 공공 API로 전송합니다.

5. 앱이 접근하는 데이터 및 기기 정보

항목접근하는 내용목적
인터넷 공용 캐시 서버 및 서울특별시·경기도·국토교통부(TAGO) 대중교통 API 요청 지하철·버스 실시간 도착 및 시간표 조회
알림 표시 앱 자체 안내 알림(운행 중 상태·도착 요약 등) 표시 예약된 안내 시간 동안 상태를 보여 줌
포그라운드 서비스 예약된 시간 동안 백그라운드에서 도착 정보 폴링·음성 안내 화면을 끄거나 다른 앱을 쓰는 중에도 안내 유지
정확한 알람 사용자가 설정한 시각에 안내를 시작하기 위한 알람 예약 정해 둔 출근 시각에 안내 시작
부팅 완료 수신 기기 재시작 후 저장된 알람 다시 등록 재부팅 뒤에도 예약한 안내가 유지되도록 함
절전 해제 유지(WAKE_LOCK) 안내 중 기기가 잠들지 않도록 유지 안내 음성과 조회가 끊기지 않게 함

앱은 위치, 마이크, 카메라, 연락처, 저장소(사진·파일), 전화, SMS, 접근성, 알림 접근 권한을 요청하지 않습니다.

6. 기기 안에 저장되는 정보

사용자가 앱에 입력·선택한 아래 정보는 다른 앱이 접근할 수 없는 앱 전용 저장소에만 저장됩니다.

  • 출근 경로: 교통수단(지하철/버스), 역·정류장 이름 또는 번호, 호선·방면, 버스 노선·도시·정류장 식별값, 안내 시작 시각·요일·지속 시간, 사용 여부.
  • 안내 중 임시 상태: 최근 조회한 도착 분·음성 안내 단계 등(기기 안에서만 사용).

전체 출근 경로와 알람 설정은 외부로 전송하지 않으며, 개발자는 사용자 기기에 저장된 이 정보에 접근할 수 없습니다. 도착정보 조회 중인 역·정류장 식별값만 9항의 방식으로 전송됩니다. 앱은 Android 자동 백업을 끄도록 설정되어 있어, 앱 데이터가 Google 계정 백업에 포함되지 않도록 합니다.

7. 위치정보 처리 여부

앱은 위치 권한(정확한 위치·대략적인 위치)을 요청하지 않으며, GPS나 기기의 위치 서비스를 사용하지 않습니다. 사용자가 저장한 역·정류장 이름은 사용자가 직접 고른 대중교통 지점이며, 좌표를 수집하지 않습니다. 다만 이 정보는 사용자가 이용하는 정류장·역을 나타내므로, 이용 장소를 짐작하게 할 수 있습니다. 외부로 전송되는 경우는 9항에서 설명합니다.

8. 음성/마이크 처리 여부

앱은 마이크 권한을 요청하지 않으며, 사용자의 음성을 녹음·저장·전송하지 않습니다. 앱의 음성은 기기의 음성 합성(TTS) 엔진으로 안내 문장을 읽어 주는 출력 기능뿐입니다. TTS 엔진의 데이터 처리는 해당 엔진 제공자의 정책을 따릅니다.

9. 네트워크 전송 여부

앱은 실시간 도착정보를 공유하기 위해 개발자가 운영하는 Cloudflare 기반 캐시 서버를 사용하며, 경로 설정·시간표 등 일부 조회는 아래 공공 API로 직접 보낼 수 있습니다. 광고·분석 서버로 데이터를 보내지 않습니다.

9-1. 공용 도착정보 캐시 서버

받는 곳출근길 비서 공용 캐시 서버 (nomi-traffic-proxy.junsuk220.workers.dev, Cloudflare Workers)
보내는 때예약된 지하철·버스 실시간 도착 안내가 실행 중이거나 도착정보를 미리 확인할 때
보내는 정보현재 조회하는 역 이름 또는 도시 코드·정류소 식별값, 인터넷 통신에 수반되는 IP 주소·기본 HTTP 요청 정보
보내지 않는 정보전체 출근 경로, 알람 시각, 이름·연락처, 계정, 광고 ID·기기 식별자, 위치 좌표
목적같은 역·정류장 요청을 20초 동안 공유하여 공공 API 호출량을 줄이고 장애 때 최근 결과를 잠시 제공
보관서버는 역·정류장별 공공 도착정보만 캐시하며 사용자 계정과 연결하지 않습니다. Cloudflare가 처리하는 접속 정보는 Cloudflare의 개인정보 처리방침과 보존 정책을 따릅니다.
전송 방식앱과 캐시 서버 사이는 HTTPS로 암호화됩니다.

9-2. 서울특별시 지하철 API

받는 곳서울특별시 열린데이터광장 실시간 지하철 도착정보·역 정보·시간표 API (swopenapi.seoul.go.kr, openapi.seoul.go.kr)
보내는 때지하철 경로를 설정하거나, 예약된 안내가 실행 중일 때
보내는 정보
  • 역 이름, 역 코드, 요일·상하행 구분(시간표 조회 시)
  • 앱의 API 인증키(앱에 포함된 값으로, 사용자 정보가 아님)
  • 인터넷 통신 특성상 함께 전달되는 정보: 기기의 IP 주소, 기본 HTTP 요청 정보(User-Agent 등)
보내지 않는 정보위치 좌표, 계정 정보, 기기 식별자, 이름·연락처
목적해당 역의 실시간 열차 도착·시간표 정보를 받아 안내
전송 방식서울특별시 API가 제공하는 방식에 따라 암호화되지 않은 HTTP로 전송될 수 있습니다.
받는 곳의 처리서울특별시 서버에서의 처리(접속 기록 등)는 서울특별시의 개인정보 처리 방침을 따릅니다.

9-3. 서울특별시 버스 API

받는 곳서울특별시 버스 정류소·도착정보 API (ws.bus.go.kr)
보내는 때서울 버스 경로를 설정하거나 안내가 실행 중일 때
보내는 정보정류소 번호 등 조회에 필요한 식별값, API 인증키, IP·기본 HTTP 요청 정보
목적해당 정류장의 버스 도착 정보 안내
받는 곳의 처리서울특별시의 개인정보 처리 방침을 따릅니다.

9-4. 경기도 버스 API

받는 곳경기도 버스정류소·버스도착정보 API
보내는 때경기도 버스 경로를 설정하거나 안내가 실행 중일 때
보내는 정보정류소 번호·식별값, API 인증키, IP·기본 HTTP 요청 정보
목적해당 정류장의 버스 도착 정보 안내
받는 곳의 처리경기도·공공데이터포털 관련 방침을 따릅니다.

9-5. 국토교통부 TAGO 버스 API

받는 곳공공데이터포털 TAGO 버스정류소·도착정보 API
보내는 때전국(비서울) 버스 경로를 설정하거나 안내가 실행 중일 때
보내는 정보도시 코드, 정류소·노선 식별값, API 인증키, IP·기본 HTTP 요청 정보
목적해당 정류장의 버스 도착 정보 안내
받는 곳의 처리공공데이터포털·국토교통부 관련 방침을 따릅니다.

10. 제3자 제공 및 공유

앱은 사용자 데이터를 판매하거나, 광고·마케팅 목적으로 제3자에게 제공하거나 공유하지 않습니다. 앱이 기기 밖으로 보내는 정보는 9항의 캐시·공공 API 조회에 한정되며, 사용자에게 도착 정보를 안내하기 위한 처리입니다.

11. 광고 및 광고 SDK

앱에는 광고가 없으며, 광고 SDK를 포함하지 않습니다. 광고 ID를 읽지 않습니다.

12. 분석/통계 SDK

앱은 Firebase, Google Analytics, Crashlytics 등 분석·통계·충돌 보고 SDK를 포함하지 않습니다. 앱이 사용하는 외부 라이브러리는 화면 구성과 데이터 형식 변환을 위한 것(AndroidX, Material Components, kotlinx.serialization 등)이며, 이 라이브러리들은 사용자 데이터를 외부로 전송하지 않습니다.

13. 데이터 보관 및 삭제

  • 캐시 서버는 계정·전체 출근 경로를 저장하지 않으며, 역·정류장별 공공 도착정보만 임시 캐시합니다.
  • 기기 안의 출근 경로·설정은 앱 삭제 또는 앱 데이터 삭제 때까지 유지됩니다.
  • 삭제 방법: 앱을 삭제하거나, Android 설정 > 애플리케이션 > 출근길 비서 > 저장공간 > 데이터 삭제를 누르면 기기 안에 저장된 모든 앱 데이터가 삭제됩니다.
  • 캐시 서버의 기반 서비스 접속 기록과 공공 API 요청의 보관은 Cloudflare 및 각 공공기관의 방침을 따릅니다.

14. 데이터 보안

  • 기기 안의 데이터는 Android가 앱마다 분리해 보호하는 앱 전용 저장소에 저장되어, 다른 앱이 읽을 수 없습니다.
  • 앱은 외부 저장소(사진·파일 공간)에 데이터를 쓰지 않습니다.
  • 앱과 공용 캐시 서버 사이는 HTTPS로 암호화됩니다. 캐시 서버와 일부 공공 API 사이는 해당 API 제공 방식에 따라 HTTP가 사용될 수 있습니다.

15. 아동 관련 사항

앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 앱은 어떤 사용자에게서도 개인정보를 입력받지 않습니다.

16. 개인정보처리방침 변경

앱의 기능이나 데이터 처리 방식이 바뀌면 이 개인정보처리방침을 갱신하고, 이 페이지의 시행일을 함께 바꿉니다. 중요한 변경이 있으면 앱 업데이트 내용 또는 이 페이지를 통해 알립니다.
